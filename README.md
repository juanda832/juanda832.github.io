# Juanda — web portfolio

Public portfolio hosted on GitHub Pages at https://juanda832.github.io/.

- `index.html` and `es.html`: English and Spanish portfolio pages.
- `civiltelecom/`: separate published business website linked from the portfolio.
- `andes-cafe/`, `flowdesk/`: original fictional website and product concepts.
- `react-brief-builder/`: independent React concept demo with local-only interactions.

The Nexora visuals are AI-assisted design concepts, clearly labeled on the site. The portrait is AI-enhanced from Juanda's own photo. The CIVILTELECOM site uses AI-generated illustrations and its contact form does not send messages. No client counts or performance results are claimed.

- `saas-ui-localization-sample.pdf`: self-initiated English-to-Latin-American-Spanish interface-copy sample for fictional product Forma; not client work.
