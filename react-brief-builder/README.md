# Website Brief Builder — React concept demo

An independent portfolio exercise built with React 18.3.1. It lets visitors shape a fictional small-business website brief and preview the summary as they change the form.

- Uses React state and reusable components.
- Includes labeled native controls, keyboard-accessible interactions, and a responsive layout.
- “Copy brief” uses the browser clipboard when available and provides a manual-copy fallback.
- The fictional example stays in the current tab; there is no backend, analytics, or network submission.
- This is a concept demo, not client work or a claim of business results.

Open `index.html` directly or serve this folder with any static HTTP server. The React and ReactDOM UMD builds and their MIT license notices are included locally.
